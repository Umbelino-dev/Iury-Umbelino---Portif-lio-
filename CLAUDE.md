# Iury Umbelino — Portfolio

Personal portfolio. Tagline: **"Curiosity builds what comes next."** / **"A curiosidade constrói o que vem a seguir."** (per locale, `messages → hero.tagline`).
Edited like an independent one-author magazine: each section opens with a typographic thesis, shows real evidence, closes with a question.

- **Design source of truth:** Claude Design project "Iury Umbelino — Direção Criativa R01" (https://claude.ai/artifact/8pT6pxPLwinMeP1UBA8UnM). Pages: *Direção Criativa R01* (tokens, type, rules), *Homepage R02* (sections, copy, interactions), *Case Study R01* + *Mobile R01*, *Cat Journey R03* (cat state machine; supersedes *Cat States R02*). When the design and this file disagree on a token, Direção Criativa R01 wins.
- **Content sources of truth:** Iury's CV and the portfolio audit (Claude Docs). Typed in `src/content/`.
- **Redesign R2 + R3 (2026-11-09/10)** override the design on: display face (now **Satoshi**), the hero (lettered name mark), the removed Night→Day screen, the cat rail and state machine, the dot cursor, the bilingual tagline and the section markers. See NOTES.md.
- Progress and open questions live in `NOTES.md`, not here.

## Hard rule — no fabrication
Never invent achievements, metrics, test results, clients, testimonials, dates, roles or contact details. The design's copy is mostly placeholder. A fact without a source stays `undefined` and the UI omits it; data copied from the design carries `confirmed: false`. Never present unshipped work as shipped.

## Stack
- Next.js 16 App Router, React 19, TypeScript strict (`noUncheckedIndexedAccess`), `src/`, `@/*` alias.
- **Static export** (`output: "export"`) → Cloudflare Workers static assets (`wrangler.jsonc`, `./out`). No middleware, route handlers that need a runtime, server actions, ISR or image optimisation. `/` → `/pt` via `public/_redirects` (+ meta-refresh fallback in `src/app/page.tsx`).
- Tailwind CSS v4, CSS-first: all tokens in `src/app/globals.css` `@theme`. No `tailwind.config`.
- GSAP + ScrollTrigger + `@gsap/react` only (no second motion library). Import from `@/lib/gsap`, never from `gsap` directly.
- next-intl 4: locales `pt` (default) and `en`, `localePrefix: "always"`. Every page/layout under `[locale]` calls `hasLocale` + `setRequestLocale` and exports `generateStaticParams`. UI strings in `messages/{pt,en}.json` (pt is the type source); facts in `src/content/*` with `Localized<T>` fields.
- Fonts self-hosted via `next/font/local` (`src/fonts/*.woff2`): **Satoshi** variable (wght 300–900, display, `font-display`; titles 700, numerals 900), **IBM Plex Sans** 400/400i/500/600 (body, `font-sans`, OFL), **Instrument Serif** italic (`font-serif`, OFL) is loaded but unused on the home (Iury, 2026-11-11: the curved face did not work); annotations (`text-note`: dates, status, captions, field names) are Satoshi Medium in a muted tone. The hero statement is Satoshi. No monospace anywhere.
- **Satoshi licence (ITF Free Font License):** self-hosting on this site and making wordmarks are allowed; modifying the font (subsetting, conversion) and distributing it, including through this **public** repo, are not. So the Satoshi files are never committed (`.gitignore`): `scripts/fonts.mjs` fetches the official package before every build (`npm prebuild`; `--lettering` also fetches the TTF for the lettering script). Never commit, subset or convert them.

Type scale (`text-*`, fluid 375→1440): `display-xxl` 208→64, `display-xl` 120→48, `headline-l` 64→36, `headline-m` 40→28, `title` 24→20, `numeral` 96→56 (Satoshi); `lead` 22→19, `body` 17→16 /1.62 max 68ch, `ui` 15, `caption` 13 (Plex); `text-note` 16 (Satoshi 500, muted). The display face never below 14px. On dark, titles under 40px go one weight up. Display breaks are hand-set per breakpoint; `text-wrap: balance` is the safety net.

Layout: `page-grid` utility = 12 cols (gutter 24, margin up to 56, max 1440) / 4 cols mobile (gutter 16, margin 20). Asymmetric: text 7 cols, air 5 — never centred by default. Spacing base 8; sections 160 desktop / 96 mobile. Radius 0, no rules or dividers on content, no shadows, no decorative gradients, no rounded cards. Pill + glass only for floating controls (nav, assistant). Project status is said in words (`StatusMark` renders the label in `text-note`).

Accent on light: use the `highlight` utility (sized gradient that stays inside tight display leading), never `bg-signal` on inline text.

Surfaces: Hero dark → About light → Projects light → Lab dark → Approach light → Contact dark. Case study: light editorial. Mark light sections `data-surface="light"` (switches focus ring to ink). The nav hit-tests the line 44px from the top, so clipped layers report correctly; `data-nav-as` on a layer overrides the active item; dispatch `SURFACE_EVENT` (`components/layout/surface.ts`) when a surface changes without scrolling.

## Components
- Server Components by default. `"use client"` only for interaction, browser APIs or animation (Nav theme, HeroMotion, PhotoDeck, Timeline, ProjectList floating image, CatAssistant, Cursor, SplitReveal).
- **Section titles:** every home section opens with its name as the h2 (`SectionTitle`: Satoshi 900 at display size, the hero's voice): Sobre, Projetos, Lab, Abordagem, Contato. No section numbers, no "(01)" labels, no rules between sections (Iury, 2026-11-10). The section's thesis follows as a large display paragraph.
- **About:** title → thesis + lead → the three traits side by side, each word whole and sized to its column (`@container`, `13cqw`, never hyphenated or wrapped) → `PhotoDeck` → experience → the career path as `Timeline`.
- **PhotoDeck** (after Iury's reference video, 2026-11-11; replaced the endless PhotoLoop, which was janky): a deck of 3–4 large cards (photos repeat up to 4 until more real photos exist). The front card is centred at full size; the neighbours tuck behind it, smaller, turned outward (a fan); with 4 cards the opposite one waits hidden. GSAP tweens only when the front changes (transform + opacity). Auto-deals every 3.4 s only while visible, not hovered/focused, tab shown, and with motion allowed. Click a side card, swipe/drag, ←/→, or the caption buttons under the deck. Each card: rounded portrait (the one exception to radius 0), a rim of light, a soft drop shadow, and a frosted base made from a pre-blurred copy of the same photo under a gradient mask (never `backdrop-filter`: it made the strip stutter).
- **Timeline:** one line drawn left to right (≥1024) or top to bottom (smaller), like an After Effects trim path scrubbed to the scroll, with a lime point of light at its tip. The roles stand in four columns, each one `--rise` higher; the path is built from their measured positions (flat under each role, S-curve up to the next; rebuilt on resize). A role waits faded (`[data-tl-anim]`, JS + motion only) until the tip passes under it. Hover/focus quiets the others and unrolls details in the free space above the role; touch shows them always; click/Enter opens the account under the line (Esc closes). Reduced motion: line fully drawn, all roles lit. Step texts live in `experience.path` (`summary`, `details`, `more`); the drafts are `confirmed: false` until Iury reviews them, and they claim no tasks or results.
- Folders: `components/layout` (primitives), `components/sections` (home), `components/case-study`, `components/media`, `components/cat`. Extract a component for real reuse or a clear responsibility, not per element.
- Images: sources in `assets/media/`, processed by `npm run images` (`scripts/images.mjs`) into `public/media/<name>-<w>.webp`; `next/image` uses the custom loader `src/lib/image-loader.ts` (widths = `images.deviceSizes`). Reference `/media/<name>.webp` in content. The two portraits are aligned and cropped together in that script — re-measure `ALIGN` if a photo changes. Brand pieces with text keep their native ratio (`aspect: "1200/630"`), never cropped.
- The hero intro paragraph is the mobile LCP element: never give it an entrance fade.
- **Projects:** `ProjectList` (Iury preferred it to the carousel, 2026-11-11): each project is a large name with one line (status + year, tags); rows are separated by space, no codes or rules. Fine pointer: hovering a name fades the others to 25% and a 4:3 image follows the cursor (lerp 0.14, tilt ≤ 4°, edge flip, 200ms crossfade); keyboard focus anchors it right. Touch: the image sits above each name. Missing covers show the typographic poster (`ProjectImage`).
- Project and Lab markup are generated from `src/content/projects.ts` and `src/content/lab.ts`; never hand-duplicate their copy. Real media goes in `cover` / `media` (`MediaImage`); without it the UI draws the editorial placeholder.
- Case studies: `/[locale]/projects/[slug]`, generated only for projects whose `caseStudy.confirmed` is true (`getCaseStudies()` in `src/content/projects.ts`; `dynamicParams = false`). Chapters without body/steps/figures are not rendered — never fill one with invented copy (e.g. "What I learned" stays out until Iury writes it). On mobile, text blocks keep `max-md:pr-12`: the right 48px are the cat lane; figures run full bleed under it.
- Never link to a destination that does not exist (no dead "#" links, no "read the study" without a study).
- Fixed/sticky overlays that span the width (the nav strip) must be `pointer-events: none`, with only their controls re-enabled.

## Graphic system (R7: no markers)
Iury, 2026-11-11: no marking patterns (codes like T.01 / E.02 / P.01, numbered labels, rulers, hairline rules, square markers, grids, crop marks, crosshairs). Structure comes from type, scale, space and imagery.
- **Voices:** Satoshi names (titles, projects, roles, actions) and, in Medium + a muted tone, annotates (`text-note`: a date, a status, a caption, a field name, "imagem em breve"). Plex explains (reading text). No monospace, no italic serif, no tracked uppercase eyebrows.
- **Order without numbers:** sequences read through placement and scale (the Approach verbs step down; the career roles climb and grow). If a list is a sequence, let the layout say it.
- **Separation by space, not lines.** Lists are spaced paragraphs; a field name in serif above its value replaces a label + rule.
- **Links and actions:** Satoshi bold with an underline (the one line allowed: a typographic affordance), or the paper/ink block button. Nav active item: full opacity, others 65%.
- **Pictures, not wireframes:** a project without a cover gets a typographic poster (its own name in Satoshi Black, cropped by the frame, `ProjectImage`); case-study slots without media show a tone and one serif line. The Lab's pointer study is a hand-drawn stroke (SVG), not a grid.
- **Allowed accents:** the lime `highlight` (max 2 per viewport), grain + soft light on dark surfaces, the cat, the lettered name. The cat's `SectionRail` stays: it is the cat's prop, not a content marker.
- **Interaction feedback:** hover/focus quiets siblings (opacity) and unrolls details in place (clip-path), never a floating popover. Panels open under what opened them with a clip-path reveal (`DUR.slow`).
- **The one drawn line:** the career path is a single animated line (Iury asked for it). It is the only line on content; it is drawn, not a rule.

## Motion
- Durations: fast 160 (hover/focus), base 320 (states/panels), slow 640 (entrances/reveal). One easing: `--ease-out-soft` `cubic-bezier(0.2,0.7,0.1,1)`.
- Animate only transform, opacity, clip-path, mask. Never layout properties.
- Use `useGSAP` (scoped context, auto-revert) and `gsap.matchMedia()` with `MQ` from `@/lib/gsap`. Kill ScrollTriggers, listeners and observers on unmount.
- Content is present in the server HTML. Entrance start states live in CSS under `.js` (class added by an inline script in `[locale]/layout.tsx`) inside `prefers-reduced-motion: no-preference`, with a 3s CSS failsafe; GSAP then animates with `fromTo` (zero any `y` GSAP would parse from the CSS) and no `clearProps`.
- `prefers-reduced-motion`: no jumps, lerps or breathing; instant swaps or hard cuts. The global reset uses `transition: none` — never a tiny duration (it makes computed styles lag a frame).
- Scroll stages: the element with the tall height must be the sticky element's direct parent.
- Effects always use a block body: `useEffect(() => { … })`. Never return an expression — e.g. `scrollIntoView()` now returns a Promise in Chromium, which React then tries to call as the cleanup and crashes.
- No always-on rAF loops: loops start on interaction and stop on idle or `visibilitychange`. The one exception is GSAP's own ticker while a tween runs.

## The cat
One character. `CatFigure` (SVG, `data-cat` parts) is the only drawing; `CatObserver` is S1 (a button: it opens the assistant); `CatAssistant` owns S2–S5 with the typed FSM in `src/components/cat/states.ts` — transitions only via `send(event)`. Any other "ask the cat" control dispatches `CAT_OPEN`. Answers are scripted in `messages/*.json → assistant` and must only use verified facts; free text matches chip keywords or gets the honest "I'm a scripted prototype" fallback. **Rail vs dock:** from 1440px with a fine pointer (home only), S3 is the R03 rail: `SectionRail` (hairline + section ticks in the right page margin) and the cat hangs on it with its paws, riding the page and climbing back to the 40% reading line (lerp, rAF only while moving); idle → it slides down and curls at the rail base. Below 1440 the margin is narrower than the 44px cat, so S3 is the bottom-right dock (as R03 mobile). The `rail:` Tailwind variant pads anything that sits in that margin. Panel open/close timelines live outside the per-state `gsap.context` (`panelTl`) so a state change cannot kill them mid-way. States: S1 observer (hero slot, head ±10°/eyes ±3px toward pointer, no reaction over text) → S2 jump (420ms arc, hero 60% out of view) → S3 cling (30px right rail, follows the 40% reading line, lerp 0.12) → S4 sleep (4s idle, curls bottom-right: **the curled cat is the closed assistant button**, 56px, `aria-label`) → S5 awaken (panel 360×520 max grows from the cat via clip-path; `role="dialog"`, Esc closes, focus in/out). Mobile: no rail — a bottom-right dock and a bottom sheet. Never opens by itself, never covers copy or nav. Same geometry, graphite body, lime eyes in every state.
**R3 motion system:** every move is a clip in `src/components/cat/clips.ts` (stretch, walk, run, crouch, airborne, falling, grab, land, settle, wake, greet, tailFlick): pure functions returning GSAP timelines on the `data-cat` parts (incl. the two front legs). In the hero, `CatObserver` scrubs stretch → walk left over the "n" → turn → run to the edge of the "o" → crouch (0–48% of the hero; reverses on scroll back). `CatAssistant` owns the FSM: observer → jump (crouch, airborne, apex clamped under the nav, falling, grab on the rail / land in the dock) → cling → sleep (on the rail: lets go, falls, lands, curls; bounded breathing) → waking (wake + stretch, then `WOKE`) → cling; any awake/asleep state → awaken (the scripted assistant) → sleep. An OPEN during the leap waits for the landing. At Contact the awake cat greets once (wave + the "Ask the cat" hint). The hero counts as left at 50% (`HERO_LEFT_AT`).

## Hero, copy and cursor (Redesign R2)
- **Hero:** the h1 is `<NameMark>`: "Iury / Umbelino" lettered as SVG paths by `scripts/lettering.py` (Satoshi read at wght 900 without instancing, kerning via HarfBuzz, every glyph run through a pathops union) into `src/components/hero/name-paths.ts` (generated, never hand-edit). The y and the b are one outline (`ligature`): Satoshi's y is a V; it is cut where its cross-section equals the b stem width (found by bisection), and a vertical stem of that width runs straight down onto the b's stem axis, so the y reads as a Y-like fork whose foot is the b. y = why, b = build. The viewBox includes every descender and nothing masks the mark. Desktop placement uses the script's `anchors` (% of the mark). Desktop: the name and the intro share one column as wide as the mark, centred horizontally, the name centred vertically above the intro; line 1 and line 2 are flush left (the script splits the gap between the two lines' tracking, `ALIGN_SPLIT`). The name comes first on every width, the positioning line and link under it (no edition line, no index rule). The statement is Satoshi 500 (not italic); mobile (< 768px) puts it under the name, left-aligned, with the cat at the row's end, and it does not fade there. Glyphs rise and the ligature draws (clip rect height) only under `.js` + motion, with the 3s failsafe. Share images: `node scripts/og.cjs` → `public/og-image-{pt,en}.png` after a lettering or copy change.
- **Copy:** short sentences, plain words, no em-dashes in UI copy (use a full stop, a comma or `·`). `npm run copy:check` counts em-dashes (fails above 3) and lists sentences over 24 words. Iury's own words (the Koinonia lesson) stay verbatim.
- **Cursor** (`components/layout/Cursor.tsx`): one 8px dot exactly on the pointer (no ring, no lag, no I-beam over text: Iury found it noisy); 18px over links and buttons, a small label pill beside it for `data-cursor-label`. Mounts only on `(hover: hover) and (pointer: fine)`; `pointer-events: none`, `aria-hidden`; form fields keep the native cursor. Opt in with `data-cursor-label="…"` (labels in `messages → cursor`) or `data-cursor="none"` for elements that draw their own pointer (Lab frames). Never use it to carry information that is not also in the page.
- **Section titles:** `data-split` makes a title rise word by word on first view (SplitText, no line masks). Skipped above the fold, for headings with a `highlight`, and with reduced motion.

## Accessibility & performance gates
Semantic landmarks, one h1 per page, ordered headings; visible focus; hit targets ≥44px; text contrast ≥4.5:1; works with keyboard, touch and reduced motion; no hover-only content (on `(hover: none)` project images sit above titles). Image width/height always set; LCP image prioritised; no layout shift from fonts. Never report Lighthouse/CWV numbers that were not measured.
